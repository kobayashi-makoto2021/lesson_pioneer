# レッスン12: 自由制作① — 企画・設計して作りはじめよう

## できるようになること

- [ ] レッスン01〜11で習った概念の中から、使いたいものを3つ以上選べる
- [ ] 作りたい作品を、他の人に説明できる形で企画できる
- [ ] 作る順番（ToDoリスト）を決めて、設計図にできる
- [ ] 4回で完成できる大きさに、やりたいことを調整できる
- [ ] 設計図にそって制作をスタートできる

## このレッスンで必要な知識

### ここからの4回でやること

今日からの**4回**は、自分だけの作品を作る時間だよ。

| 回 | やること |
|---|---|
| **レッスン12（今日）** | 企画・設計して、制作をスタート |
| レッスン13 | 制作 |
| レッスン14 | 遊んでもらって直す・仕上げ |
| レッスン15 | 発表 |

レッスン07でも企画をしたね。あのときはレッスン06までの概念だった。今はキュー・スタック・二分探索・シャッフルも使える。**道具が増えた状態で、もう一度本気で企画しよう。**

レッスン07の企画をふくらませてもいいし、まったく新しいものを考えてもいいよ。

### 使える概念カタログ

これまでに習った14個の道具だよ。この中から**3つ以上**を選んで使おう。

| 概念 | どんな道具？ | 習った回 |
|---|---|---|
| ループアンドスイッチ | ずっと繰り返しながら、条件で動きを切り替える | 01 |
| カウンター変数 | 数を数える（点数・回数・タイム） | 01 |
| フラグ変数／ループアンドフラグ | オン・オフを覚える。条件が来るまでループを続ける | 02 |
| 乱数 | 毎回ちがう数を作る | 03 |
| ランダム探索 | でたらめに動きながら探す | 03 |
| XY座標 | 場所を2つの数（x, y）で表す | 03・04 |
| 二重ループ | ループの中にループ。マス目を全部まわる | 04 |
| ステートマシン | 「いまどの場面か」を変数で管理する | 05 |
| 全探索 | しらみつぶしに全部調べる。必ず見つかる | 05 |
| リスト | データを何個でも入れておける箱 | 06 |
| キュー（FIFO） | 先に入れたものから出る。行列・順番待ち | 08 |
| スタック（LIFO） | 後に入れたものから出る。「戻る」機能 | 09 |
| 線形探索／二分探索 | データの中から目当てのものを探す。二分探索は超高速 | 10 |
| シャッフル／ID・対応表 | 順番をまぜる。番号で別のデータを引く | 11 |

### 4回で終わる大きさって？

一番よくある失敗は、**作りたいことが多すぎて時間切れになる**ことだよ。

作れる時間は、**60分 × 3回ちょっと**。だいたいこのくらいが目安だよ。

| ちょうどいい | 大きすぎる |
|---|---|
| ステージ（場面）は1つ | ステージが5つある |
| ルールが1つか2つ | ルールがたくさんあって説明が長い |
| スプライトは2〜4個 | キャラクターを10種類作る |
| 遊ぶ時間は1〜2分 | 30分遊べる大作 |

> **大事なコツ：** 小さく作って、余ったら足す。最初から大きく作ると、何もできあがらないまま最終回になっちゃうよ。

### 設計図を作る理由

いきなりブロックを並べはじめると、たいてい途中で「あれ、次なにを作るんだっけ？」となる。

先に**作る順番**を決めておくと、毎回のレッスンで「今日はここまで」がはっきりして、迷わずに進められるんだ。プロのプログラマーも必ずやっていることだよ。

## ミッション

作品を企画・設計して、制作をスタートしよう！

---

### ステップ1: アイデアを決めよう

作りたいものを書き出そう。

```
タイトル：

どんな作品？（ひとことで）：

どこが面白い？：

遊ぶ人は何をする？：
```

**アイデアが出ないときのヒント**

- レッスン07で考えた企画を見返してみよう。今なら作れるかも？
- これまでに作ったプログラムを改造するとしたら？（宝探し・二分探索AI・シャッフルなど）
- 好きなゲームの「一部分だけ」をtoioで再現するとしたら？
- toioを2台使うなら、どんな役割にする？（追いかける／かくれる／協力する）

---

### ステップ2: 使う概念を3つ以上選ぼう

カタログから選んでチェックしよう。

- [ ] ループアンドスイッチ
- [ ] カウンター変数
- [ ] フラグ変数／ループアンドフラグ
- [ ] 乱数
- [ ] ランダム探索
- [ ] XY座標
- [ ] 二重ループ
- [ ] ステートマシン
- [ ] 全探索
- [ ] リスト
- [ ] キュー
- [ ] スタック
- [ ] 線形探索／二分探索
- [ ] シャッフル／ID・対応表

選んだ概念が、作品の**どこで使われるか**まで書こう。ここが一番大事だよ。

```
概念①「          」→ どこで使う：

概念②「          」→ どこで使う：

概念③「          」→ どこで使う：
```

> **チェック：** 「使う」と書いただけで、どこで使うか言えないものは、まだ企画に入っていないのと同じだよ。

---

### ステップ3: 画面の絵をかこう

完成したときの画面を、絵でかいてみよう。文字だけよりずっと伝わるよ。

かきこむこと。

- スプライト（キャラクター）は何がいる？
- 画面に出す変数（点数・残り時間・状態など）はどれ？
- toioはどう動く？（矢印でかいてみよう）

---

### ステップ4: 作る順番を決めよう

やることを小さく分けて、**作る順番**に並べよう。4〜7個くらいに分けるとちょうどいいよ。

| 順番 | やること | できた？ |
|---|---|---|
| 1 | | ☐ |
| 2 | | ☐ |
| 3 | | ☐ |
| 4 | | ☐ |
| 5 | | ☐ |
| 6 | | ☐ |
| 7 | | ☐ |

**順番を決めるコツ**

- **いちばん大事な部分を1番に**する。「これがないと作品にならない」というところだよ
- 見た目・音・演出は**あとまわし**。動く仕組みが先！
- 1つが大きすぎたら、さらに2つに分けよう

> **考えてみよう：** もし時間が足りなくなったら、どれを削る？ 削ってもいい番号に印をつけておこう。

---

### ステップ5: 制作スタート！

設計図ができたら、さっそく作りはじめよう。**ステップ4の「1番」から**だよ。

**作るときのルール**

- **少し作ったら、すぐ動かす。** 全部作ってから動かすと、どこが悪いのかわからなくなるよ
- できたらToDoリストにチェックを入れよう
- うまくいかないところは、あとで質問できるようにメモしておこう

**今日の終わりに**

- [ ] ファイルを保存した（`日付名前番号.sb3` の形式だよ）
- [ ] ToDoリストにチェックを入れた
- [ ] 次回いちばん最初にやることを、1行書いた

```
次回いちばん最初にやること：
```
