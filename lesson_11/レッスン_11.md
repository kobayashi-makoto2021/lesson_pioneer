# レッスン11: バブルソート — 隣同士を比べて並び替えよう

## できるようになること

- [ ] バブルソートの仕組み（隣同士を比べて入れ替える）を説明できる
- [ ] フローチャートを読んで、プログラムを組み立てられる
- [ ] 一時保存の変数を使って、2つの値を入れ替える方法がわかる
- [ ] 比較回数を数えて、アルゴリズムの速さを調べられる

## このレッスンで必要な知識

### なぜ「並び替え」が必要なの？

レッスン10でやった二分探索を思い出そう。「真ん中を試して、半分に絞る」がうまくいくのは、データが**小さい順に並んでいる**からだったよね。

でも、実際のデータはバラバラなことが多い。バラバラのデータを順番に並べることを「**ソート**（並び替え）」というよ。今日はいちばん基本のソート、「**バブルソート**」を作るよ！

### バブルソートってなに？

やることはたった1つ。

> **隣同士を比べて、左のほうが大きかったら入れ替える。**

これをリストの左から右まで順番にやっていくと、**いちばん大きい数が右端まで移動する**んだ。泡（バブル）が水の中をのぼっていくように、大きい数が端まで浮かんでいくから「バブルソート」というよ。

1回やっただけでは全部は並ばない。だから、**入れ替えが1回も起きなくなるまで**、何周もくりかえすんだ。

### 2つの値の入れ替え — 一時保存のテクニック

「1番目と2番目を入れ替える」を、そのまま書くと失敗するよ。

- 1番目を2番目の値にする → **もともとの1番目の値が消えちゃった！**

コップAのジュースとコップBのジュースを入れ替えるには、**空のコップがもう1つ**必要だよね。プログラムでは「一時保存」という変数がその空のコップになるよ。

```
① 一時保存 ← 1番目の値       （Aのジュースを空のコップへ）
② 1番目 ← 2番目の値          （BのジュースをAへ）
③ 2番目 ← 一時保存           （空のコップのジュースをBへ）
```

### いつ終わればいい？ — フラグ変数でチェック

「もう並び終わった」って、プログラムはどうやって気づくんだろう？

答えは、**フラグ変数「入れ替え」**を使うこと。1周まわって**入れ替えが1回も起きなかったら**、もう全部並んでいる証拠だ。

- 周のはじめに「入れ替え」を 0 にする
- 入れ替えが起きたら 1 にする
- 周が終わっても 0 のままなら → 完成！

レッスン02でやった**ループアンドフラグ**の再登場だよ。

### 比較回数 — アルゴリズムの速さの測り方

レッスン10では「何回試したか」で探索の速さを比べたよね。ソートでは「**何回比べたか（比較回数）**」で速さを測るよ。

今日から3レッスンで、バブルソート → 選択ソート → クイックソートと3つのソートを作って、比較回数で速さくらべをしていくよ。今日はその1つ目！

### フローチャートってなに？

プログラムの流れを図で表したものだよ。今日は、**フローチャートだけを見てプログラムを組み立てる**チャレンジをするよ！読み方はこれだけ。

- **角丸**：スタート・おわり
- **四角**：処理（ブロック1つぶん）
- **ひし形**：質問。「はい」「いいえ」で進む道が分かれる
- **ひし形から上に戻る矢印**があったら、それは**くりかえし（ループ）**だよ

バラバラの数字リストを、バブルソートで小さい順に並び替えよう！

> **考えてみよう：** 初期化では「入れ替え」だけ 1 にしているね。0 にしたらどうなっちゃうかな？（ヒント：最初の質問は「入れ替え = 0？」だよ）

### ステップ3: 生徒用プログラムを開こう

次に、**生徒用プログラム**をダウンロードして開こう。

![生徒用プログラム全体](image/生徒用プログラム.png)

このプログラムには、**関数（定義ブロック）が3つ**用意してあるよ。まず中身を読んでみよう。

![用意してある関数3つ](image/ブロック.png)

| 関数 | やっていること |
|---|---|
| リスト作成 | リストを空にして、乱数を「リストの個数」回追加する（バラバラのデータを作る係） |
| 初期化 | 変数を最初の状態に戻して、リスト作成を呼ぶ（準備の係） |
| 数の入れ替え | 「いまの位置」の数と、その右どなりの数を入れ替える（選手交代の係） |

**「数の入れ替え」の中身に注目！** 「一時保存」を使った3ステップの入れ替えが、そのまま入っているよ。空のコップの話を思い出しながら、1行ずつ読んでみてね。

旗のスクリプトは「初期化 → 2秒待つ」で止まっているね。**この続きを、フローチャートを見ながら自分で作るのが今日のミッション**だよ！

---

### ステップ4: フローチャートに従ってプログラムを作ろう

フローチャートとブロックの対応はこれだけ。あとは自分の力で組み立てよう！

| フローチャート | Scratchのブロック |
|---|---|
| ひし形＋上に戻る矢印 | 「〜まで繰り返す」 |
| ひし形（戻らない） | 「もし〜なら」 |
| 四角 | ブロック1つ |

**ヒント**

- ループは**二重**になっているよ。外側の周＝「入れ替え = 0」までくりかえす、内側＝「いまの位置 > 数字リストの長さ - 1」までくりかえす
- 「もし〜なら」の中に入れるのは、**「数の入れ替え」関数1つだけ**！入れ替えの中身は関数が全部やってくれるよ
- 最後の「終わるまで Win の音を鳴らす」は、画面に置いてあるブロックをつなぐだけ

> **考えてみよう：** 内側のループはなぜ「数字リストの長さ **- 1**」で止まるのかな？（ヒント：右端の数字に「右どなり」はいる？）

---

### ステップ5: 動かしてチェックしよう

完成したら旗を押して、正解プログラムと同じ動きになるか確かめよう！

- [ ] リストが**小さい順**に並び替わった？
- [ ] 並び終わったら **Win の音**が鳴って止まった？
- [ ] **比較回数**は増えていった？

**うまく動かないときは…**

- 止まらない → 「入れ替え を 0 にする」は**外側のループの中の先頭**にあるかな？
- 比較回数が 0 のまま → 「比較回数を 1 ずつ変える」を入れ忘れていないかな？
- 最後の数字がヘン → 内側のループの条件は「長さ **- 1**」になっているかな？

- 「入れ替え を 0 にする」「いまの位置 を 1 にする」が**周のはじめ**にある理由を、説明できるかな？

最後に、**自分のプログラムの比較回数をメモしておこう**。次のレッスンの「速さくらべ」で使うよ！

## まとめ

- バラバラのデータを順番に並べることを**ソート**という。二分探索は、ソート済みのデータだからこそ使えた！
- **バブルソート**は「隣同士を比べて、左が大きければ入れ替える」をくりかえすソート。大きい数が泡のように右端へ浮かんでいく
- 2つの値の入れ替えには**一時保存**の変数（空のコップ）が必要
- 終わりの判定は**フラグ変数「入れ替え」**：1周まわって入れ替えが 0 回なら完成
- **フローチャート**が読めれば、初めてのプログラムも設計図から組み立てられる！
- アルゴリズムの速さは**比較回数**で測る。次のレッスンでは選択ソートと速さくらべをするよ！
